# House.Mix — стартовий інтернет-магазин

## Запуск на комп'ютері
1. Встановіть Node.js LTS.
2. Відкрийте цю папку в терміналі.
3. Виконайте `npm install`
4. Виконайте `npm run dev`
5. Відкрийте `http://localhost:3000`

## Важливо
Це готовий стартовий каркас магазину з каталогом, кошиком, оформленням замовлення та демо-адмінкою. Для реального запуску потрібні база даних, серверна авторизація, збереження замовлень і підключення платіжного сервісу.

Демо пароль адмінки: `housemix`
